# **App Name**: Subhra Das Portfolio

## Core Features:

- Interactive Story: "Story Mode" Homepage: An interactive homepage that visually guides the user through Subhra’s career milestones.
- Product Journey: Timeline: An interactive timeline/product journey map showcasing the growth and evolution of Zyadashop with key metrics.
- Case Studies: Portfolio Case Studies: A dedicated section to showcase portfolio case studies with embedded Notion/Figma/Google Docs links.
- Skill Dashboard: PM Skill Board: A visually engaging skill dashboard presenting skills/tools mastered (SQL, Jira, Mixpanel, etc.) using icons and progress bars.
- Animated Metrics: Metrics Wall: Animated counters displaying key impact metrics such as downloads, DAU increase, and effort reduction.
- Current Projects: "What I’m Exploring Now" Section: Showcase of current learning projects (e.g., SQL project, AI system) to display ongoing personal projects.
- Portfolio Analyzer: AI Portfolio Optimizer: This tool uses AI to provide automated suggestions for improvement of the text portions of the portfolio based on the other PM portfolios it has seen.

## Style Guidelines:

- Primary color: Deep slate blue (#2C3E50) for a professional and trustworthy feel.
- Background color: Light gray (#F0F4F8) to ensure readability and modern aesthetic.
- Accent color: Vivid cyan (#00FFFF) for interactive elements and highlights, symbolizing innovation and forward-thinking.
- Headline font: 'Poppins', a geometric sans-serif, for a precise, contemporary feel. Body text: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look.
- Clean and structured layout with clear sections and intuitive navigation.
- Subtle micro-transitions and loading animations to maintain user engagement.
- Use modern, minimalistic icons for skills and tool representation in the PM Skill Board.
